# UniSwap UI Project

This project is a multi-screen UI prototype for a peer-to-peer textbook marketplace.

## Screens
- Listing Details Screen
- Home Screen
- Chat Screen
- Profile Screen

## Built With
- HTML
- CSS
- Font Awesome

## Purpose
UI/UX practice and interface design exploration.

## To use this code
open https://codepen.io/pen/
Paste the html, and css code in the repspective blocks on code pen. Both work together to create the final ui
